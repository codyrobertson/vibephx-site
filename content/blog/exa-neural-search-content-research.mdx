## What is Exa?

Exa is a **neural search engine** built on embeddings (like how ChatGPT understands language).

**Traditional search** (Google, Bing):
```
Query: "next.js server components tutorial"
Results: Keyword matches ("next.js", "server components", "tutorial")
Problem: Misses semantic meaning, returns SEO-optimized spam
```

**Neural search** (Exa):
```
Query: "Show me technical articles explaining React Server Components with code examples"
Results: Semantically similar content (understands intent, not just keywords)
Bonus: Filters by domain authority, recency, content type
```

**Key difference**: Exa understands **what you mean**, not just **what you said**.

```typescript
// lib/services/research.ts
import { exa } from '@/lib/exa'
import { callLLM } from '@/lib/llm-client'

interface ResearchData {
  claims: Array<{
    claim: string
    source: string
    confidence: number
    category: string
  }>
  codeExamples: Array<{
    language: string
    code: string
    description: string
    source: string
  }>
  statistics: Array<{
    metric: string
    value: string
    source: string
    confidence: number
  }>
  overallConfidence: number
}

export async function researchTopic(
  topic: string,
  category: string
): Promise<ResearchData> {
  // 1. Search with Exa
  console.log(`[Research] Searching Exa for: ${topic}`)

  const searchResults = await exa.search(topic, {
    numResults: 10,
    useAutoprompt: true,
    type: 'neural',
    startPublishedDate: '2024-01-01',
    includeDomains: getDomainsByCategory(category),
    contents: {
      text: true,
      highlights: {
        numSentences: 5,
        highlightsPerUrl: 3
      }
    }
  })

  console.log(`[Research] Found ${searchResults.results.length} articles`)

  // 2. Synthesize with GPT-5
  const prompt = `
You are a technical researcher analyzing content about "${topic}".

Your task:
1. Review these search results
2. Extract key technical claims, statistics, and code patterns
3. Rate your confidence in each claim (0-100)
4. Only include claims with confidence >= 70

Search Results:
${searchResults.results.map((r, i) => `
[${i + 1}] ${r.title}
URL: ${r.url}
Published: ${r.publishedDate}
Highlights:
${r.highlights?.join('\n')}

Full Text (excerpt):
${r.text?.slice(0, 2000)}
`).join('\n\n---\n\n')}

Output JSON format:
{
  "claims": [
    {
      "claim": "Specific technical claim",
      "source": "https://...",
      "confidence": 0-100,
      "category": "performance|architecture|api|tooling"
    }
  ],
  "codeExamples": [
    {
      "language": "typescript|javascript|python|etc",
      "code": "actual code snippet",
      "description": "what this code does",
      "source": "https://..."
    }
  ],
  "statistics": [
    {
      "metric": "What was measured",
      "value": "Specific number/percentage",
      "source": "https://...",
      "confidence": 0-100
    }
  ],
  "overallConfidence": 0-100
}
`

  const response = await callLLM({
    model: 'openai/gpt-5',
    messages: [
      { role: 'system', content: 'You are a technical researcher.' },
      { role: 'user', content: prompt }
    ],
    temperature: 0.3,  // Low temp for factual analysis
    maxTokens: 4000
  })

  const researchData: ResearchData = JSON.parse(response.content)

  console.log(`[Research] Extracted ${researchData.claims.length} claims`)
  console.log(`[Research] Overall confidence: ${researchData.overallConfidence}`)

  return researchData
}

function getDomainsByCategory(category: string): string[] {
  const domainMap: Record<string, string[]> = {
    'react': ['react.dev', 'nextjs.org', 'remix.run', 'vercel.com'],
    'typescript': ['typescriptlang.org', 'github.com/microsoft'],
    'node': ['nodejs.org', 'github.com/nodejs'],
    'ai': ['openai.com', 'anthropic.com', 'huggingface.co'],
    'database': ['postgresql.org', 'mongodb.com', 'planetscale.com']
  }

  return domainMap[category] || []
}
```

### 3. Citation Generation

Automatically cite sources in content:

```typescript
function generateCitations(researchData: ResearchData) {
  const citations = new Map<string, number>()
  let citationCounter = 1

  // Assign citation numbers
  researchData.claims.forEach(claim => {
    if (!citations.has(claim.source)) {
      citations.set(claim.source, citationCounter++)
    }
  })

  // Format as footnotes
  const footnotes = Array.from(citations.entries())
    .map(([url, num]) => `[${num}] ${url}`)
    .join('\n')

  return { citations, footnotes }
}

// Usage in article

## References
${footnotes}
`
```

## Lessons Learned

### 1. **Date Filtering is Critical**

Without date filtering, Exa returns outdated content.

```typescript
// ❌ Bad: No date filter
const results = await exa.search(topic)

// ✅ Good: Only recent content
const results = await exa.search(topic, {
  startPublishedDate: '2024-01-01'
})
```

### 2. **Domain Whitelisting Improves Quality**

General web search returns noise. Whitelist authoritative domains.

```typescript
includeDomains: ['nextjs.org', 'react.dev', 'vercel.com']
```

### 3. **Use Autoprompt for Complex Queries**

Let Exa optimize your query instead of manually engineering it.

```typescript
useAutoprompt: true  // Exa expands "Next.js perf" to detailed query
```

### 4. **Highlights > Full Text for GPT-5**

Sending full article text (10,000+ tokens) is expensive. Use highlights.

```typescript
contents: {
  highlights: {
    numSentences: 5  // Only most relevant sentences
  }
}
```

**Savings**: 90% reduction in GPT-5 input tokens.

### 5. **Confidence Scoring Prevents Hallucinations**

GPT-5 can misinterpret research. Make it score confidence and reject low scores.

```typescript
if (researchData.overallConfidence < 75) {
  throw new Error('Research confidence too low, need more sources')
}
```
